Active Learning Designer: installation & usage

Install the skill, develop an activity around your learning goal, and refine it before requesting any optional delivery files.

Install or start a conversation

  1. Download Active Learning Designer.
  2. If your AI assistant supports skill installation, use its supported installation flow for the ZIP or extracted folder. Keep the folder structure intact. The archive contains SKILL.md, README.md and four files in references/.
  3. If it has no skill installer but supports file uploads, extract the ZIP and attach SKILL.md and all four reference files to a conversation. Ask the assistant to use them as Active Learning Designer. This provides the instructions for that conversation; it does not install a permanent skill.
  4. Share a teaching goal or appropriate course material. Describe constraints that matter, such as learner level, available time, class size or delivery mode. Remove student identifiers, confidential information and materials you do not have permission to share. Your AI assistant’s file and privacy rules apply.

There is no installation on this website. Skill support and file-generation capabilities vary across AI environments.

Start with the work students should do

For example:

Use Active Learning Designer to adapt this lecture segment into an activity. Students should explain the concept and apply it to a new situation. I have 20 minutes, including setup and debrief, with 60 students in a classroom. Give me an activity I can run, student instructions and a brief check of understanding.

The 20-minute budget is an example of an instructor’s choice. You can specify any feasible duration or ask the skill to recommend an adjustable one. A syllabus is not required: a concept, reading, case, objective, existing exercise or teaching problem can be enough.

You can also ask it to critique an existing activity or troubleshoot silence, uneven participation or weak discussion. Review the assumptions and proposed student thinking rather than accepting the first draft automatically.

Refine the activity

Continue in the same conversation. Be specific about what to keep and what needs changing:

Keep the learning goal and student task. Make the instructions clearer and leave more time for the debrief. Keep the whole activity within my time budget.

Check that the stage timings add up, students have the materials they need, participation is accessible, and the learning check asks for more than enjoyment or attendance. The instructor remains responsible for disciplinary accuracy and local requirements.

Request delivery files when useful

After agreeing on the activity, you can say:

Generate the Classroom Delivery Package for this activity. Keep our latest agreed timing and instructions. Include classroom slides and a facilitator guide. Add a standalone interactive HTML tool only if it helps the intended learning. Keep instructor answers separate from the student-facing material until the planned reveal.

This is optional. You can teach from the activity text without generating files. Ask the assistant to verify that any promised downloads actually exist; available formats depend on its tools.

Choose the next useful step

Ask for the next change you need. You can request a complete activity or package immediately.

Download the Complete Toolkit to use all three independent skill folders.
