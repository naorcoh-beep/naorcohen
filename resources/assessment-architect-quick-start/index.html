Assessment Architect: installation & usage

Connect the learning goal to credible evidence, clear criteria and practical feedback.

Install or use a conversation

  1. Download Assessment Architect. The archive contains the assessment-architect folder, SKILL.md and three files in references/.
  2. Use your AI assistant’s documented skill installation or import feature if it supports one. Keep the folder and reference files together.
  3. If there is no installer but file uploads are available, attach SKILL.md and all three references to the same conversation and ask the assistant to use Assessment Architect. This supplies the instructions for that conversation; it does not install a permanent skill.
  4. Share the learning goal and appropriate assessment materials. Remove student identifiers, confidential information and material you do not have permission to upload. Your AI environment’s privacy rules apply.

You can also download the Complete Toolkit. It contains three independent skill folders. Use only the one you need or combine them within your AI assistant’s capabilities. There is no installation or assessment processing on this website.

Ask for a focused review

Use Assessment Architect to audit this assignment and rubric against the supplied learning outcomes. Identify what works, the most important threats to credible evidence of learning, and the smallest useful improvement. Preserve the assessment weights and workload. Keep the first review concise.

For an exploratory request, the shared workflow offers distinct ways to continue:

  • Revise the assignment and rubric: develop usable student-facing materials and criteria.
  • Examine validity and AI analysis: explore what the work demonstrates, alternative explanations and appropriate assistance.
  • Compare redesign options: weigh different approaches against your actual constraints.

Reply in ordinary language, combine paths, or ask for the complete output immediately.

Request materials directly

Revise the attached assignment brief and rubric now. Preserve the supplied learning outcomes, weights and permitted resources. Separate student-facing text from instructor guidance and identify any local-policy details that need verification.

A complete response depends on the request and available material. Review the task’s clarity, the evidence it elicits, the quality of the criteria and the marking effort. The instructor retains academic judgement and responsibility for policy, accessibility and disciplinary accuracy.

For a wider design question, Course Designer addresses outcomes and course alignment, while Active Learning Designer develops the learning experiences. Explore the connected Toolkit.
